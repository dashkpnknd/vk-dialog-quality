# VK Квалы — бот для оценки рекламных диалогов

Программа работает на сервере. Она читает диалоги сообществ VK, отличает самостоятельные ответы клиентов от нажатий кнопок бота, считает долю «квалов» по числовым рекламным меткам, записывает подробности в Google-таблицу и отправляет краткий отчёт в Telegram.

## Команды бота

- `/report` — сразу показывает последнюю доступную сводку и ставит обновление VK в очередь; после обработки группы её отчёт отправляется в тему.
- `/campaign ID` или кнопка «🎯 Кампании» — поиск числового рекламного ID сразу по всем магазинам за последние 30 дней. Если ID есть в нескольких сообществах, результаты показываются отдельно. Кнопка есть и в панели General подключённого чата.
- `/today` — сводка за сегодня.
- `/group ID` — результаты по рекламным ID одного магазина.
- `/groups` — подключённые магазины.
- `/newgroup` — подключить сообщество по одному ключу доступа VK; ID и название определяются автоматически.
- `/city Название проекта ; Город` — задать город проекта для отдельной темы в Telegram.
- `/sheet` — ссылка на Google-таблицу.
- `/sync` — запустить сбор вручную.
- `/status` — состояние сбора.

Доступ получает любой пользователь, знающий общую команду `/startКОД` и отправивший её в личный чат бота. Сам код хранится только в `.env` сервера как `BOT_ACCESS_CODE`, без записи в публичный репозиторий. После пяти неверных попыток ввод блокируется на час. `/start` без кода не открывает данные. Ежедневный сбор ставится в очередь после 03:00 по Москве; готовые отчёты в темах публикуются после 10:00 или после завершения сбора. Кнопка «📊 Отчёт» сразу показывает последнюю доступную сводку; `/status` показывает ход очереди.

Кнопка «📊 Отчёт» сразу показывает последнюю доступную сводку и ставит обновление в постоянную очередь SQLite. Отдельный процесс обходит группы с ограниченным числом обработчиков (по умолчанию восемь), сохраняет прогресс по каждому чату и пропускает неизменившиеся диалоги. Истории до 20 чатов читаются одним пакетным запросом VK, а длинные истории дочитываются отдельно. Задания переживают перезапуск, повторные запросы во время обработки не теряются, ошибки повторяются с паузой. Пока группа не прошла первый полный сбор, её частичные данные не включаются в отчёт. Отдельная кнопка «Собрать данные» убрана. Кнопка «📄 Таблица» открывает подробную Google-таблицу; для просмотра отчётов она не требуется. Кнопка «Помощь» убрана.

## Отчёты по городам в Telegram

Добавьте бота в супергруппу Telegram с включёнными темами и правом администратора «Управлять темами». Авторизованный пользователь отправляет `/connect`; бот создаёт темы магазинов и одну панель с кнопками в General. Для закрепления панели боту требуется право «Закреплять сообщения». Кнопка «Отчёт» в General ставит обновление VK в очередь и показывает последнюю доступную сводку. Кнопки срабатывают только для пользователей, которые ввели общую команду доступа боту в личном чате. Данные собираются ежедневно после 03:00 по Москве; готовые отчёты публикуются в темах после 10:00 по Москве. Отдельный блок «Вчера» не публикуется.

Для нового сообщества в личном чате нажмите «➕ Подключить VK» и отправьте только ключ доступа сообщества с правом читать сообщения. Бот сам узнает ID и полное название из VK и создаст проект. Название темы будет соответствовать названию сообщества. Если нужно исправить город в ранее созданном проекте, используйте `/city Название проекта ; Город`. Пустые тестовые проекты не получают тему до появления обращений.

## Предварительные правила подсчёта

1. Если в истории человека появляется новая числовая рекламная метка, создаётся новое обращение. Старое остаётся в отчёте. Повторяющиеся сообщения с той же меткой относятся к одному обращению.
2. Самостоятельный ответ может прийти в любой день после обращения: при следующем сборе прежний результат пересчитается.
3. Самостоятельный текст и вложения, включая фото, видео и голосовые, считаются ответом. Нажатия кнопок не считаются.
4. Когда текст совпал с кнопкой, но VK не передал `payload`, диалог попадает в «Проверить вручную».

Если в старом диалоге появился новый ответ, но VK не показал новой рекламной метки, бот не может приписать этот ответ новой кампании. Спорные случаи видны отдельно.

## Что ещё требуется для настоящего запуска

- Токен Telegram-бота от BotFather.
- Токены сообществ VK с доступом к сообщениям и числовые ID сообществ.
- Google-таблица и сервисный аккаунт Google с правом её редактирования.
- Проверка на одном реальном диалоге: совпадают ли поля VK API `ref`/`ref_source` с рекламной меткой в интерфейсе и как API передаёт нажатия кнопок.

Эти данные **не входят в репозиторий**. Сообщения клиентов в базе не сохраняются; хранятся только ID собеседника, метка и результат подсчёта.

## Установка на сервере

Требуется Docker с Compose. В папке проекта:

```bash
cp .env.example .env
mkdir -p data secrets
docker compose up -d --build
```

В `.env` заполните `TELEGRAM_BOT_TOKEN` и `BOT_ACCESS_CODE`. Для подключения новой VK-группы используйте кнопку «➕ Подключить VK» в личном чате Telegram. Сообщение с ключом бот попытается удалить сразу после получения. Telegram уже получает этот ключ до удаления сообщения; используйте этот способ только если такое хранение приемлемо. Альтернативно добавляйте токены через консоль сервера:

```bash
docker compose exec bot python main.py add-group "Название магазина" 123456789
```

Команда скрыто запросит токен сообщества. Затем проверьте метки без вывода текста переписки и токена:

```bash
docker compose exec bot python main.py probe 123456789 --limit 10
```

После подключения группы бот сам ставит первый сбор в очередь. `/status` покажет её ход, `/report` — готовые показатели. До добавления первого сообщества статистика будет пустой.

## Google-таблица

Создайте таблицу и поделитесь ею с адресом `client_email` сервисного аккаунта Google как с редактором. JSON-ключ сервисного аккаунта поместите в `secrets/google-service-account.json`; ID таблицы укажите в `.env` как `GOOGLE_SPREADSHEET_ID`. Бот создаст вкладки «Сводка» и «По дням» в этой таблице. Перезапустите контейнер после изменения `.env`.

## Локальные проверки

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
```

Для ручного отчёта без Telegram: `.venv/bin/python main.py report --days 30`. Для обработки без бота: `.venv/bin/python main.py sync --days 30`.

**Масштабирование:** задания по группам хранятся в SQLite, а обработчики работают в отдельном контейнере. `VK_SYNC_WORKERS` задаёт число одновременных групп в одном контейнере. Скорость первого сбора зависит от числа чатов за 30 дней и ограничений VK API; `/status` показывает, сколько групп уже готово.
