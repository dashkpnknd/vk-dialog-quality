# Спецификация: качество обращений из рекламы VK

## Задача

Для каждого магазина нужно увидеть, какие рекламные метки приводят людей, которые вступают в переписку. Бот не оценивает покупку или качество консультации: «квал» означает только самостоятельный ответ клиента. Источник задачи — присланные видео и скриншоты VK.

## Источники данных

- Один проект — один магазин. У проекта может быть несколько сообществ VK.
- Для каждого сообщества нужен токен с доступом к сообщениям. `messages.getConversations` даёт список диалогов, `messages.getHistory` — их историю.
- Числовая рекламная метка извлекается из `ref` или `ref_source` сообщения. Оба варианта текста на скриншотах («Из рекламы ВКонтакте» и «Из VK Рекламы») приводятся к числовому ID.
- Если числовой ID отсутствует, обращение попадает в строку «Без метки». Бот не пытается угадать рекламу: в эту строку могут попасть и органические обращения, и реклама с потерянной меткой.

## Единица подсчёта

Единица отчёта — **обращение** человека в конкретном сообществе, а не уникальный человек за всё время.

1. Начало нового диалога без рекламной метки создаёт обращение «Без метки».
2. Появление числовой рекламной метки создаёт обращение с этим ID.
3. Позднее появление **другого ID** в том же диалоге начинает новое обращение. Прошлое обращение остаётся в отчёте.
4. Повтор той же метки без смены ID остаётся в текущем обращении. Пока нельзя достоверно выделить повторный клик по тому же объявлению без отдельного признака VK.
5. Новое сообщение в старом диалоге **без новой метки** не приписывается новой рекламе.

В базе ключ обращения включает ID сообщества, ID собеседника и ID сообщения, на котором впервые обнаружена соответствующая метка. Повторный сбор обновляет ту же запись и не умножает статистику.

## Определение квала

- Самостоятельный текст, фото, видео, голосовое и другое вложение клиента = квал.
- Сообщение сообщества, в том числе автоответ бота, не является ответом клиента.
- Входящее сообщение с `payload` кнопки не является квалом.
- Если входящий текст совпал с известным названием кнопки, а `payload` отсутствует, обращение помечается «Проверить вручную». Это защищает отчёт от ложного квала.
- Обращение без самостоятельного ответа пока считается «не квалом». Если клиент ответит позже, результат пересчитается независимо от срока ответа. Поэтому доля за последние дни может измениться.

## Периоды и отчёт

Первый и ежедневный сбор просматривают диалоги с активностью за последние 30 календарных дней по Москве. Для ранее сохранённого не квалифицированного обращения с новой активностью история читается от его исходной даты, чтобы поздний ответ мог исправить старый результат. Если история одного диалога превышает лимит чтения, он не классифицируется молча: сбор показывает число пропущенных диалогов.

По каждому проекту, сообществу и ID метки считаются:

- всего обращений;
- квалов;
- не квалов;
- требующих ручной проверки;
- доля квалов = квалы / всего обращений × 100%.

Telegram — основной интерфейс. Кнопка «Отчёт» присылает сводку и полный CSV со всеми рекламными ID; `/group ID` показывает подробности одного сообщества в чате. Google Sheets хранит сводку и разбивку по дням. Ежедневный запуск происходит после 03:00 по Москве, а кнопка «Обновить» запускает сбор вручную.

## Граница подтверждённой работы

На тестовых историях проверены сообщения и вложения, кнопки, смена рекламной метки, повторный сбор, поздний ответ, отсутствие метки, отчёты и работа Telegram. Запись в предоставленную Google-таблицу проверена на сервере. **Реальная атрибуция VK остаётся непроверенной**, пока не будет подключено первое сообщество: нужно сравнить числовую метку в интерфейсе VK с полями `ref` и `ref_source` API, а также проверить `payload` кнопок. До этого нельзя честно обещать совпадение процентов с ручным подсчётом.

Telegram-бот по решению владельца открыт всем пользователям, включая добавление проектов и сообществ. Токен VK при добавлении через чат приходит в Telegram; бот удаляет сообщение после получения, но доставка в Telegram уже состоялась. Для более строгого хранения токен можно вводить через консоль сервера.
